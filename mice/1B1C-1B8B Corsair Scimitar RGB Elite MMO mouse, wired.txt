Corsair Scimitar RGB Elite MMO mouse (1b1c:1b8b), wired

VID:PID    1B1C:1B8B
Type       Real device
Source     https://github.com/hrvach/deskhop/issues/45

Notes
  - Interface 0 (boot mouse) has a mouse with 32 buttons and 16-bit X/Y (report 1), consumer (2),
    vendor (3, 14) and a keyboard bitmap (16, for the side keypad). Interface 1 is vendor. Real
    mouse reports from usbhid-dump --entity=stream.

Interfaces
  Interface 0: class 03 (HID), subclass 01 (boot), protocol 02 (mouse), endpoint max packet 64 bytes
  Interface 1: class 03 (HID), subclass 00, protocol 00, endpoint max packet 64 bytes
