Afatech "USB Gaming Mouse" (1b80:b40c), boot mouse with 16-bit X/Y plus a keyboard interface

VID:PID    1B80:B40C
Type       Real device
Source     Big Mess o' Wires customer report, 2017 (lsusb -v output, converted to bytes)

Notes
  - Interface 1 (subclass 0, protocol 1) has a keyboard (report 1), system control (2), consumer
    (3), an ABSOLUTE 16-bit mouse collection (4) and a vendor collection (6). Interface 2 (vendor,
    32-byte endpoints) is left out: lsusb showed its descriptor as UNAVAILABLE.
  - bInterval is 1 ms on interface 0.

Interfaces
  Interface 0: class 03 (HID), subclass 01 (boot), protocol 02 (mouse), endpoint max packet 8 bytes
  Interface 1: class 03 (HID), subclass 00, protocol 01, endpoint max packet 8 bytes
