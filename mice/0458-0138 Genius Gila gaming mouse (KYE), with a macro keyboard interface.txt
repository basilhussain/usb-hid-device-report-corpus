Genius Gila gaming mouse 0458:0138 (KYE), with a macro keyboard interface

VID:PID    0458:0138
Type       Real device
Source     https://github.com/bentiss/hid-devices/tree/master/events/mouse

Notes
  - Recorded with hid-recorder, with real reports. Interface 0: mouse (report 1, 16-bit X/Y).
    Interface 1: a boot keyboard used for macro buttons (sends "5" in the recording). Interface 2:
    vendor.
  - Next to a real keyboard, a simple host may pick the mouse's keyboard interface as the keyboard.

Interfaces
  Interface 0: class 03 (HID), subclass 01 (boot), protocol 02 (mouse), endpoint max packet 8 bytes
  Interface 1: class 03 (HID), subclass 01 (boot), protocol 01 (keyboard), endpoint max packet 8 bytes
  Interface 2: class 03 (HID), subclass 00, protocol 00, endpoint max packet 8 bytes
