Notes
  - Interface 0: boot mouse, 1000 Hz (bInterval 1). Interface 1 (subclass 0, protocol 1): keyboard
    (report 1), consumer (2), system control (3), vendor (4, 5). Interface 2: boot keyboard (macro
    keys).
  - Other Basilisk V2 firmware revisions have a Logical Maximum of 572 in an 8-bit field; in this
    unit's descriptor the 572 is in a 16-bit field (consumer usage, interface 1).
  - Real reports are from interface 0 (buttons 1-5 incl. side buttons, movement, wheel).
