Logitech gaming mouse with HID++ (model not given; constant device in QMK issue #19472)

VID:PID    046D:C0xx (PID unknown)
Type       Real device
Source     https://github.com/qmk/qmk_firmware/issues/19472

Notes
  - Interface 0: 16-button mouse with 16-bit X/Y. Interface 1: keyboard (report 1, for G-key
    macros), consumer, system and HID++ (reports 0x10/0x11).

Interfaces
  Interface 0: class 03 (HID), subclass 01 (boot), protocol 02 (mouse), endpoint max packet 8 bytes
  Interface 1: class 03 (HID), subclass 00, protocol 00, endpoint max packet 64 bytes
  The source gave only the report descriptors. Subclass and protocol were inferred from them (a
  descriptor that starts with a Keyboard or Mouse collection and has no report IDs was taken as a
  boot interface), and endpoint sizes were assumed.
