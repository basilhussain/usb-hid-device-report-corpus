Separate USB numeric keypad (generic boot keyboard device)

VID:PID    xxxx:xxxx (none, not a real device)
Type       Example descriptor from the HID 1.11 specification (not a real device)
Source     USB Device Class Definition for HID 1.11, Appendix E.6 (keyboard) and E.10 (mouse)

Notes
  - A stand-alone keypad usually presents itself exactly like a keyboard: a boot keyboard interface
    with the standard descriptor.

Interfaces
  Interface 0: class 03 (HID), subclass 01 (boot), protocol 01 (keyboard), endpoint max packet 8 bytes
