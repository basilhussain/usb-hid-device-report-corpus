pico-fido security key (Raspberry Pi Pico firmware using the YubiKey OTP+FIDO VID/PID)

VID:PID    1050:0407
Type       Real device
Source     https://github.com/polhenarejos/pico-fido/issues/67

Notes
  - Open-source FIDO key firmware that also types one-time passwords as a keyboard. Its keyboard
    descriptor contains Report ID (0), which the HID specification reserves.
  - Security keys that are also keyboards can be mistaken for the main keyboard by simple hosts.

Interfaces
  Interface 0: class 03 (HID), subclass 00, protocol 00, endpoint max packet 8 bytes
  Interface 1: class 03 (HID), subclass 00, protocol 00, endpoint max packet 8 bytes
  The source gave only the report descriptors. Subclass and protocol were inferred from them (a
  descriptor that starts with a Keyboard or Mouse collection and has no report IDs was taken as a
  boot interface), and endpoint sizes were assumed.
