PCsensor FootSwitch USB foot pedal (QinHeng)

VID:PID    1A86:E026
Type       Real device
Source     https://gitlab.freedesktop.org/libevdev/udev-hid-bpf/-/tree/main/src/bpf/userhacks/0010-QuinHeng__PCsensor-FootSwitch.bpf.c

Notes
  - Interface 0 has keyboard (report 1), mouse (report 2), a joystick-like collection and consumer
    control in one interface; the pedal sends keyboard reports. Interface 1 is a "Pointer"
    collection with 8-byte input that sends nothing. Interface subclass/protocol values are assumed.

Interfaces
  Interface 0: class 03 (HID), subclass 01 (boot), protocol 01 (keyboard), endpoint max packet 8 bytes
  Interface 1: class 03 (HID), subclass 00, protocol 00, endpoint max packet 8 bytes
