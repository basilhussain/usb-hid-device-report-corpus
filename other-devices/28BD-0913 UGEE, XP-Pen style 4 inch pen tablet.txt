UGEE / XP-Pen style 4 inch pen tablet (28bd:0913): mouse, digitizer, keyboard for express keys

VID:PID    28BD:0913
Type       Real device
Source     https://github.com/DIGImend/digimend-kernel-drivers/issues/388

Notes
  - Graphics tablets often expose a keyboard interface for their express keys and a mouse interface.

Interfaces
  Interface 0: class 03 (HID), subclass 00, protocol 00, endpoint max packet 64 bytes
  Interface 1: class 03 (HID), subclass 00, protocol 00, endpoint max packet 64 bytes
  Interface 2: class 03 (HID), subclass 00, protocol 00, endpoint max packet 8 bytes
  The source gave only the report descriptors. Subclass and protocol were inferred from them (a
  descriptor that starts with a Keyboard or Mouse collection and has no report IDs was taken as a
  boot interface), and endpoint sizes were assumed.
