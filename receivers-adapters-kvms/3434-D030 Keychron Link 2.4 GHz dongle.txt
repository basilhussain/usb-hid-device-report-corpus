Keychron Link 2.4 GHz dongle (3434:d030 / d031), e.g. Keychron V1 Max, K15 Max

VID:PID    3434:D030
Type       Real device
Source     https://github.com/hrvach/deskhop/issues/211

Notes
  - Descriptors and real reports from usbhid-dump on a Raspberry Pi (4 interfaces). Interface 2 is a
    boot keyboard interface, but sends 9-byte reports with report ID 1.
  - Interface classes are from a Windows dump of the same dongle in the same issue (3 interfaces
    there: 0 boot mouse, 1 vendor, 2 boot keyboard; interface 1's descriptor is 115 bytes there and
    167 here, so probably different dongle firmware). Interface 3 (34 bytes) is assumed to be a
    non-boot interface. libusb warned that the configuration descriptor had 7 bytes left over.

Interfaces
  Interface 0: class 03 (HID), subclass 01 (boot), protocol 02 (mouse), endpoint max packet 64 bytes
  Interface 1: class 03 (HID), subclass 00, protocol 00, endpoint max packet 64 bytes
  Interface 2: class 03 (HID), subclass 01 (boot), protocol 01 (keyboard), endpoint max packet 32 bytes
  Interface 3: class 03 (HID), subclass 00, protocol 00, endpoint max packet 64 bytes
