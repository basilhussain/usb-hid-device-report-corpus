Notes
  - Reported problem with a simple host: keyboard works, mouse doesn't. IOGEAR (ATEN's brand) KVMs
    had the same symptom.
  - The dump has report descriptors only. Interface class/subclass/protocol and endpoint sizes are
    assumed: boot keyboard on 0, boot mouse on 2.
  - Interface 3 is an ABSOLUTE pointer (X/Y 0..0x3FFF); interface 2 is the relative mouse that sends
    the recorded reports.
