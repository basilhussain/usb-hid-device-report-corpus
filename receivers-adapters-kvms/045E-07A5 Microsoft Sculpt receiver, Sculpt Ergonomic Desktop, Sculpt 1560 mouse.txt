Microsoft Sculpt receiver (045e:07a5), Sculpt Ergonomic Desktop / Sculpt 1560 mouse

VID:PID    045E:07A5
Type       Real device
Source     https://github.com/hrvach/deskhop/issues/367

Notes
  - Interface 0: boot keyboard; interface 1: mouse (report 0x1A, 16-bit X/Y, wheel and AC Pan with
    resolution multipliers); interface 2: consumer and vendor collections. Real mouse reports from
    usbhid-dump --entity=stream (move left/right/up/down, left/right/middle click, back, scroll
    left/right).

Interfaces
  Interface 0: class 03 (HID), subclass 01 (boot), protocol 01 (keyboard), endpoint max packet 8 bytes
  Interface 1: class 03 (HID), subclass 00, protocol 00, endpoint max packet 16 bytes
  Interface 2: class 03 (HID), subclass 00, protocol 00, endpoint max packet 32 bytes
  The source gave only the report descriptors. Subclass and protocol were inferred from them (a
  descriptor that starts with a Keyboard or Mouse collection and has no report IDs was taken as a
  boot interface), and endpoint sizes were assumed.
