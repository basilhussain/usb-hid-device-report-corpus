Feenix Autore keyboard (SONiX 0c45:????), 160-key bitmap keyboard

VID:PID    0C45:xxxx (PID unknown)
Type       Real device
Source     Big Mess o' Wires customer report, 2021 (usbhid-dump output)

Notes
  - Interface 0 has modifiers and a 160-bit key bitmap (usages 0-0x9F) with no report ID; interface
    1 has consumer (report 1) and system control (report 2) keys.
  - The product ID and interface subclass/protocol were not in the report; interface 0 is assumed to
    be a boot keyboard interface (subclass 1, protocol 1), as usual for SONiX keyboards.

Interfaces
  Interface 0: class 03 (HID), subclass 01 (boot), protocol 01 (keyboard), endpoint max packet 64 bytes
  Interface 1: class 03 (HID), subclass 00, protocol 00, endpoint max packet 8 bytes
