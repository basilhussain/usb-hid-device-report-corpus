Type       Real device
Source     https://ratatoskr.run/qemu-devel/2026/07/17280285/t (QEMU patch "Apple Magic Keyboard and
           Mighty Mouse emulators"; the author says the descriptors were captured from real
           hardware)

Notes
  - Interface 0 is Apple vendor-defined. Interface 1 is a boot keyboard interface whose report
    descriptor uses report IDs: keyboard report 1 (modifiers, reserved, 6 keys, Eject, vendor bits),
    consumer report 0x52, vendor 0x3F.

Interfaces
  Interface 0: class 03 (HID), subclass 00, protocol 00, endpoint max packet 64 bytes
  Interface 1: class 03 (HID), subclass 01 (boot), protocol 01 (keyboard), endpoint max packet 8 bytes
