Logitech G810 Orion Spectrum gaming keyboard

VID:PID    046D:C337
Type       Real device
Source     https://github.com/qmk/qmk_firmware/issues/19472

Notes
  - Interface 1 holds a second keyboard collection (report 1: a 20-byte key array with the modifiers
    as array entries) and consumer control. Works through a TESmart KVM (QMK issue #19472), which
    reads the boot interface.
  - A host that reads interface 1 and assumes the boot layout (modifiers at byte 1, keys from byte
    3) decodes it wrongly.

Interfaces
  Interface 0: class 03 (HID), subclass 01 (boot), protocol 01 (keyboard), endpoint max packet 8 bytes
  Interface 1: class 03 (HID), subclass 00, protocol 00, endpoint max packet 64 bytes
  The source gave only the report descriptors. Subclass and protocol were inferred from them (a
  descriptor that starts with a Keyboard or Mouse collection and has no report IDs was taken as a
  boot interface), and endpoint sizes were assumed.
