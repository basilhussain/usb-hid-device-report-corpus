Corsair K70 CORE RGB keyboard, interface 0 (first 38 bytes of its descriptor)

VID:PID    1B1C:1BFD
Type       Real device
Source     https://gitlab.freedesktop.org/libevdev/udev-hid-bpf/-/tree/main/src/bpf/testing/0010-Corsair__K70-CORE.bpf.c

Notes
  - Only the first 38 bytes of the 125-byte interface 0 descriptor are published; an End Collection
    is added here. Report ID 8: modifiers and a key array declared with 13 slots and Logical Maximum
    1, but the device sends 19 slots: 21-byte reports, not the declared 15.

Interfaces
  Interface 0: class 03 (HID), subclass 01 (boot), protocol 01 (keyboard), endpoint max packet 64 bytes
