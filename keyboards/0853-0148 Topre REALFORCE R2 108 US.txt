Topre REALFORCE R2 108 US (0853:0148)

VID:PID    0853:0148
Type       Real device
Source     https://gitlab.freedesktop.org/libinput/libinput/-/issues/804
           https://gitlab.freedesktop.org/libevdev/hid-tools/-/issues/39

Notes
  - Interface 0 boot keyboard; interface 1 starts with Consumer Control, then an NKRO keyboard. With
    NKRO switched on, keys go to interface 1 (libinput issue "NKRO on Topre Realforce R2 keyboard").
    Interface numbers assumed.

Interfaces
  Interface 0: class 03 (HID), subclass 01 (boot), protocol 01 (keyboard), endpoint max packet 8 bytes
  Interface 1: class 03 (HID), subclass 00, protocol 00, endpoint max packet 64 bytes
  The source gave only the report descriptors. Subclass and protocol were inferred from them (a
  descriptor that starts with a Keyboard or Mouse collection and has no report IDs was taken as a
  boot interface), and endpoint sizes were assumed.
