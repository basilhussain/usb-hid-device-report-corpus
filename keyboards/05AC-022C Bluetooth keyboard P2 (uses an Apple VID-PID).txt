Bluetooth keyboard "P2" using Apple's VID/PID 05ac:022c (keyboard, digitizer, consumer)

VID:PID    05AC:022C
Type       Real device
Source     https://gitlab.freedesktop.org/libinput/libinput/-/issues/1014

Notes
  - A cheap keyboard that presents itself as an Apple Aluminum Wireless Keyboard (Bluetooth
    descriptor).

Interfaces
  Interface 0: class 03 (HID), subclass 00, protocol 00, endpoint max packet 64 bytes
  The source gave only the report descriptors. Subclass and protocol were inferred from them (a
  descriptor that starts with a Keyboard or Mouse collection and has no report IDs was taken as a
  boot interface), and endpoint sizes were assumed.
