Corsair STRAFE RGB gaming keyboard (1b1c:1b20), BIOS mode (switch on the keyboard)

VID:PID    1B1C:1B20
Type       Real device
Source     https://github.com/hrvach/deskhop/issues/45

Notes
  - In BIOS mode the keyboard has only interface 0, a plain boot keyboard with 8-byte endpoints
    (lsusb in the same issue).

Interfaces
  Interface 0: class 03 (HID), subclass 01 (boot), protocol 01 (keyboard), endpoint max packet 8 bytes
