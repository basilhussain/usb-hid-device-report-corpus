Microsoft Surface Type Cover (045e:07e8): keyboard + touchpad, 1071-byte descriptor

VID:PID    045E:07E8
Type       Real device
Source     https://gitlab.freedesktop.org/libinput/libinput/-/issues/321

Notes
  - Keyboard report 1 has no reserved byte: the key array starts right after the modifiers. A
    decoder that assumes the boot layout reads the keys one byte late.

Interfaces
  Interface 0: class 03 (HID), subclass 00, protocol 00, endpoint max packet 64 bytes
  The source gave only the report descriptors. Subclass and protocol were inferred from them (a
  descriptor that starts with a Keyboard or Mouse collection and has no report IDs was taken as a
  boot interface), and endpoint sizes were assumed.
