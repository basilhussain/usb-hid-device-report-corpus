Notes
  - Interface 0: vendor; interface 1: boot keyboard interface whose keyboard report has report ID 1
    (10 bytes), plus consumer and vendor collections; interface 2: vendor. A host that treats it as
    a boot keyboard without sending SET_PROTOCOL(boot) reads the report ID (1) as the modifier byte,
    so Left Control looks held down.
