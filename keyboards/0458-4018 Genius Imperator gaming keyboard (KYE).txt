Genius Imperator gaming keyboard 0458:4018 (KYE)

VID:PID    0458:4018
Type       Real device
Source     https://github.com/bentiss/hid-devices/tree/master/events/keyboard

Notes
  - Recorded with hid-recorder, with real reports. Interface 0 is the boot keyboard and carries the
    typing. Interface 1: mouse and consumer control. Interface 2 declares a 112-key keyboard bitmap
    plus 400 bits of padding (64-byte reports) and sends vendor-looking data.
  - Interface 2's keyboard has no separate modifier field (the modifier and key ranges are in one
    item). A host that uses the last keyboard interface it finds would read interface 2 instead of
    the real keyboard.

Interfaces
  Interface 0: class 03 (HID), subclass 01 (boot), protocol 01 (keyboard), endpoint max packet 8 bytes
  Interface 1: class 03 (HID), subclass 00, protocol 00, endpoint max packet 8 bytes
  Interface 2: class 03 (HID), subclass 00, protocol 00, endpoint max packet 64 bytes
