Notes
  - Transcribed from KeyboardioHID. Interface 1 is the boot keyboard; interface 0 holds the NKRO
    keyboard (report 8: modifiers, a 4-bit pad, then a bitmap of usages 4-0xDD), consumer control
    and mouse keys. The order of the non-keyboard collections in interface 0 is approximate. The
    interface order (multi-report HID before the boot keyboard) depends on Arduino PluggableUSB
    constructor order and is inferred.
  - In report protocol Kaleidoscope sends keys only on the NKRO interface (interface 0); in boot
    protocol only on the boot keyboard interface. A host that reads only the boot keyboard interface
    without sending SET_PROTOCOL(boot) gets no keys.
