Razer Pro Type Ultra

VID:PID    1532:027B
Type       Real device
Source     https://github.com/openrazer/openrazer/issues/2650

Notes
  - Typical Razer keyboard layout: interface 0 is the boot keyboard; interface 1 holds another
    keyboard (report 1, a key bitmap) plus consumer, system control and mouse collections; interface
    2 is a mouse. Not verified: in report protocol Razer keyboards probably type on interface 1
    (report 1), and on interface 0 only in boot protocol.

Interfaces
  Interface 0: class 03 (HID), subclass 01 (boot), protocol 01 (keyboard), endpoint max packet 8 bytes
  Interface 1: class 03 (HID), subclass 00, protocol 00, endpoint max packet 64 bytes
  Interface 2: class 03 (HID), subclass 01 (boot), protocol 02 (mouse), endpoint max packet 64 bytes
  The source gave only the report descriptors. Subclass and protocol were inferred from them (a
  descriptor that starts with a Keyboard or Mouse collection and has no report IDs was taken as a
  boot interface), and endpoint sizes were assumed.
