Apple Keyboard A1048 (05ac:020c), white USB keyboard with a built-in 2-port hub

VID:PID    05AC:020C
Type       Real device
Source     Big Mess o' Wires: dumped from the device, 2026 (exact bytes, real reports)

Notes
  - The keyboard sits behind its own built-in hub (2 USB ports; with the keyboard itself, 3 USB
    addresses). The A1242/A1243 aluminum keyboards are the same design. Interface 0: boot keyboard;
    interface 1: consumer keys. Reports are from interface 0 in boot protocol.

Interfaces
  Interface 0: class 03 (HID), subclass 01 (boot), protocol 01 (keyboard), endpoint max packet 8 bytes
  Interface 1: class 03 (HID), subclass 00, protocol 00, endpoint max packet 4 bytes
