Holtek based gaming keyboard 04d9:a055, with its second interface

VID:PID    04D9:A055
Type       Real device
Source     https://github.com/torvalds/linux/blob/master/drivers/hid/hid-holtek-kbd.c

Notes
  - Interface 1 is the kernel's holtek_kbd_rdesc_fixed without its added LED block, with the
    consumer Usage/Logical Maximum restored to the original 0x7FFF. It holds System Control,
    Consumer Control (32768 usages) and a keyboard bitmap.
  - Interface 0 is not given in the source; assumed to be a standard boot keyboard (the HID 1.11
    example).

Interfaces
  Interface 0: class 03 (HID), subclass 01 (boot), protocol 01 (keyboard), endpoint max packet 8 bytes
  Interface 1: class 03 (HID), subclass 00, protocol 00, endpoint max packet 8 bytes
