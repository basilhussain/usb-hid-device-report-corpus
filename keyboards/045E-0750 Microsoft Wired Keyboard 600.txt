Microsoft Wired Keyboard 600 (045e:0750)

VID:PID    045E:0750
Type       Real device
Source     https://github.com/hrvach/deskhop/issues/297

Notes
  - Interface 0: boot keyboard; interface 1: consumer and system control keys.
  - This is model 1366 (2014). Model 1576 (2016) is 045e:07f8: from an lsusb -v on
    linux-hardware.org (probe 428a86ff5a), its interface 0 is a boot keyboard with a 65-byte report
    descriptor and an 8-byte endpoint like this one, and interface 1 (03 00 00) has a 52-byte
    descriptor and a 3-byte endpoint.

Interfaces
  Interface 0: class 03 (HID), subclass 01 (boot), protocol 01 (keyboard), endpoint max packet 8 bytes
  Interface 1: class 03 (HID), subclass 00, protocol 00, endpoint max packet 8 bytes
