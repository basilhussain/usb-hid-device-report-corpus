Royal Kludge RK61 RGB wired (2022)

VID:PID    xxxx:xxxx (unknown, probably SinoWealth 258a or a rebrand)
Type       Real device
Source     https://github.com/carlossless/sinowisp/issues/37

Notes
  - SinoWealth-based: the chip family behind many cheap gaming keyboards and mice (VID 258a and
    rebrands). The VID and PID were not in the dump.

Interfaces
  Interface 0: class 03 (HID), subclass 01 (boot), protocol 01 (keyboard), endpoint max packet 8 bytes
  Interface 1: class 03 (HID), subclass 00, protocol 00, endpoint max packet 64 bytes
  The source gave only the report descriptors. Subclass and protocol were inferred from them (a
  descriptor that starts with a Keyboard or Mouse collection and has no report IDs was taken as a
  boot interface), and endpoint sizes were assumed.
