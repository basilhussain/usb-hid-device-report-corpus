Maltron L90 ergonomic keyboard (Alcor), with its original buggy second interface

VID:PID    058F:9410
Type       Real device
Source     https://github.com/torvalds/linux/blob/master/drivers/hid/hid-maltron.c

Notes
  - maltron_rdesc_o, the original descriptor that the kernel replaces (System Control and Consumer
    Control with bad ranges).
  - Interface 0 is not given in the source; assumed to be a standard boot keyboard (the HID 1.11
    example).

Interfaces
  Interface 0: class 03 (HID), subclass 01 (boot), protocol 01 (keyboard), endpoint max packet 8 bytes
  Interface 1: class 03 (HID), subclass 00, protocol 00, endpoint max packet 8 bytes
