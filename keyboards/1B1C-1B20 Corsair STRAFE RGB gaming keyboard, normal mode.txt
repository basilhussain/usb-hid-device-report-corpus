Corsair STRAFE RGB gaming keyboard (1b1c:1b20), normal mode

VID:PID    1B1C:1B20
Type       Real device
Source     https://github.com/hrvach/deskhop/issues/45

Notes
  - Interface 0 is a boot keyboard interface, but its report is a 152-key bitmap with report ID 1
    (21 bytes), plus consumer (2) and vendor (3, 14) collections. Interface 1 is vendor. Real
    reports from usbhid-dump --entity=stream.
  - The keyboard's BIOS-mode switch changes it to a plain boot keyboard (see the BIOS mode file).

Interfaces
  Interface 0: class 03 (HID), subclass 01 (boot), protocol 01 (keyboard), endpoint max packet 64 bytes
  Interface 1: class 03 (HID), subclass 00, protocol 00, endpoint max packet 64 bytes
