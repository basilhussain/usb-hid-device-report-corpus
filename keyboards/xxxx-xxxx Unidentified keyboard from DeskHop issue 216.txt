Keyboard from DeskHop issue "Keyboard keys alphabetically shifted" (interfaces 2-4)

VID:PID    xxxx:xxxx (unknown)
Type       Real device
Source     https://github.com/hrvach/deskhop/issues/216

Notes
  - Its keyboard collection is not the usual layout; DeskHop decoded keys one position off.

Interfaces
  Interface 2: class 03 (HID), subclass 01 (boot), protocol 01 (keyboard), endpoint max packet 8 bytes
  Interface 3: class 03 (HID), subclass 00, protocol 00, endpoint max packet 64 bytes
  Interface 4: class 03 (HID), subclass 01 (boot), protocol 02 (mouse), endpoint max packet 8 bytes
  The source gave only the report descriptors. Subclass and protocol were inferred from them (a
  descriptor that starts with a Keyboard or Mouse collection and has no report IDs was taken as a
  boot interface), and endpoint sizes were assumed.
