SiGma Micro based keyboard 1c4f:0059, with its second interface

VID:PID    1C4F:0059
Type       Real device
Source     https://github.com/torvalds/linux/blob/master/drivers/hid/hid-sigmamicro.c

Notes
  - sm_0059_rdesc as sent by the device (the kernel then changes byte 99). SiGma Micro chips are
    common in cheap keyboards.
  - Interface 0 is not given in the source; assumed to be a standard boot keyboard (the HID 1.11
    example).

Interfaces
  Interface 0: class 03 (HID), subclass 01 (boot), protocol 01 (keyboard), endpoint max packet 8 bytes
  Interface 1: class 03 (HID), subclass 00, protocol 00, endpoint max packet 8 bytes
