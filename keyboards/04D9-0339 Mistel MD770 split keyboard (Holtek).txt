Mistel MD770 split keyboard (Holtek)

VID:PID    04D9:0339
Type       Real device
Source     https://gitlab.freedesktop.org/libevdev/udev-hid-bpf/-/tree/main/src/bpf/stable/0010-Mistel__MD770.bpf.c

Notes
  - Sends the first 6 keys held at once on interface 0, and any more on interface 1: a keyboard
    bitmap that comes after a System Control collection. Interface 1 is the original descriptor from
    the BPF source.
  - Interface 0 is not given in the source; assumed to be a standard boot keyboard (the HID 1.11
    example).

Interfaces
  Interface 0: class 03 (HID), subclass 01 (boot), protocol 01 (keyboard), endpoint max packet 8 bytes
  Interface 1: class 03 (HID), subclass 00, protocol 00, endpoint max packet 16 bytes
